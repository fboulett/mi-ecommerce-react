# APEX STORE

APEX STORE es una simulación de tienda online desarrollada con React, Vite y Firebase. La aplicación permite a los usuarios navegar por productos, registrarse, iniciar sesión y utilizar funciones de gestión de productos desde una interfaz sencilla y moderna.

## ¿Qué incluye?

- Simulación de tienda con catálogo de productos.
- Registro e inicio de sesión de usuarios.
- Perfil de usuario autenticado.
- Gestión de productos para crear, editar, actualizar stock y eliminar productos.
- Integración completa con Firebase Authentication y Firestore.
- Diseño responsive con navegación por páginas.

## Tecnologías utilizadas

- React
- Vite
- React Router
- Firebase Authentication
- Firestore
- CSS Modules

## Funcionalidades principales

### Usuarios

- Crear una cuenta nueva.
- Iniciar sesión con email y contraseña.
- Acceder a su perfil.

### Productos

- Ver productos en la tienda.
- Crear nuevos productos desde el formulario de gestión.
- Editar productos existentes.
- Aumentar o disminuir stock.
- Eliminar productos del catálogo.

## Configuración

1. Clona este repositorio.
2. Instala las dependencias:
   ```bash
   npm install
   ```
3. Configura tus credenciales de Firebase en el archivo de configuración correspondiente.
4. Inicia la app:
   ```bash
   npm run dev
   ```
